Instrucciones para GitHub Pages

¡Sube tu catálogo digital gratis en menos de 5 minutos utilizando GitHub Pages! Sigue estos sencillos pasos:

Paso 1: Crear un Repositorio

Entra a GitHub, inicia sesión y crea un nuevo repositorio público (por ejemplo: boofi-papeleria).

Paso 2: Subir este archivo

Guarda todo el código de esta página como un archivo llamado index.html. Súbelo al repositorio haciendo clic en "Add file" -> "Upload files" y arrastra el archivo. Luego haz clic en "Commit changes".

Paso 3: Activar GitHub Pages

  1. En tu repositorio, ve a la pestaña Settings (Configuración).
  2. En el menú de la izquierda, busca la sección Pages.
  3. En Build and deployment -> Branch, selecciona la rama main (o master) y la carpeta / (root).
  4. Haz clic en Save.

Paso 4: ¡Listo! Tu web en línea

Espera 1 o 2 minutos y recarga la página de configuración en GitHub Pages. Te aparecerá la URL pública de tu catálogo lista para compartir en Instagram y WhatsApp.
